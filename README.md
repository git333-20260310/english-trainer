# English Trainer

英語丸暗記アプリの教材データを使う、1問ずつの暗記トレーナーです。

## できること

- 日本語から英語を答える
- 英語から日本語を答える
- ランダム出題
- 未チェックだけ表示
- 完璧に覚えたもの以外を復習
- iPhoneの読み上げ用に、今のカードのテキストを選択

## 公開URL

GitHub Pagesを有効にすると、次のURLで開けます。

## YouTube区間リピート

YouTube動画の開始・終了時間を指定して、好きな区間だけを繰り返し再生できます。

- YouTube、短縮URL、ShortsのURLに対応
- 現在位置から開始・終了時間を登録
- 区間リピート、速度変更、リピート回数
- お気に入り区間の端末保存
- 区間を含む共有URLのコピー

https://git333-20260310.github.io/english-trainer/youtube-loop.html

## メモ

教材データは english-memorizer の公開済みアプリから読み込んでいます。
そのため、例文を増やすときは english-memorizer 側を更新すれば、このトレーナー側にも反映されます。
